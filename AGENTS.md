# Repository workflow

- Make changes on a working branch, never directly on `main`.
- Push the working branch and use a pull request targeting `main` for review.
- Keep an existing open PR for subsequent pushes to the same branch.
- Run `npm run check` and `npm run build` before pushing.
- Do not merge a PR without the user's explicit instruction.
- Preserve the approved desktop layout and motif when working on mobile text.
